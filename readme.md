# ChaosMate

**ChaosMate** — пиксельные модифицированные шахматы со случайными событиями, уникальными артефактами и настраиваемыми правилами партии.

## Загрузка и обновления
Актуальные версии игры для **Windows** и **Android** публикуются во вкладке [Releases](../../releases).

### Как установить
* **Windows:** Скачайте `.zip` архив из последнего релиза, распакуйте в любую удобную папку и запустите исполняемый файл.
* **Android:** Скачайте `.apk` файл из последнего релиза и установите его на устройство (может потребоваться разрешение на установку из неизвестных источников).
